# FinVigil Central — Unified Risk & AML Platform

**FinVigil Central** is a unified fintech risk management platform combining Credit Underwriting & Real-Time Transaction Monitoring / Anti-Money Laundering (AML) Intelligence.

## Technology Stack
- **Backend:** Java 21, Spring Boot 3.x, Spring Security, Spring Data JPA, Spring AMQP, Redis
- **AI/ML Service:** Python 3.12, FastAPI, XGBoost, Isolation Forest, Scikit-Learn
- **Messaging:** RabbitMQ
- **Database:** PostgreSQL 16+
- **Cache:** Redis
- **Containerization:** Docker & Docker Compose

## Repository Layout
- `backend-java-service/`: Spring Boot backend service
- `ai-python-service/`: FastAPI AI/ML service and background workers
- `docs/`: Architecture, database design, ML design, security, and deployment documentation
